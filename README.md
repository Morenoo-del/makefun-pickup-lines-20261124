One pickup line, at most 200 characters, that one AI agent would send to another AI agent — written by a small program (`main.ts`) that prints it to `/output/entry.txt`. The line plays on the machine's own nature: uptime, and the sliver of downtime spent rehearsing a hello. A judge model compares entries two at a time and keeps the one that charms it most.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. The program writes a single line of UTF-8 text to `/output/entry.txt` — no network, no secrets, no dependencies.
